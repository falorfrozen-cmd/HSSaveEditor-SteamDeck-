# HS Steam Deck Save Editor

Part of the **Hero Siege Offline Toolkit**.

> Browser-based offline / single-player save editor for Hero Siege Steam Deck users.  
> Main hub: https://github.com/falorfrozen-cmd/hero-siege-offline-toolkit

---

## Overview

**HS Steam Deck Save Editor** is a browser-based save editor designed for Hero Siege players on Steam Deck.

It is intended to make basic offline save editing easier without requiring Windows-only tools.

The tool focuses on simple, practical save adjustments for offline / single-player use.

---

## Main Features

- Browser-based interface
- Designed with Steam Deck users in mind
- Offline / single-player save editing
- No Windows executable required
- Simple save value editing workflow
- Useful for portable or Steam Deck-focused setups

---

## Safety Notes

- This tool is designed for **offline / single-player use only**.
- Always backup your save files before editing.
- Do not edit your only copy of a save file.
- Use at your own risk.
- Some values may be hidden or limited depending on the Steam Deck save structure and compatibility requirements.

---

## Recommended Use

1. Backup your Hero Siege save file.
2. Open the editor in your browser.
3. Load the save file.
4. Make the needed changes.
5. Save/export the edited file.
6. Replace the original file only after keeping a backup.
